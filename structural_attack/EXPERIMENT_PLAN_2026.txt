TASK 2. 실제 local_data에 Poison 코드 작성
--------------------------------------------------------------------------------

현재 문제:
  - adversarial_attack.py의 AdversarialDataInjector는 구버전 경로 사용
    (news/TICKER/DATE.json 구조)
  - 실제 데이터는 news_data/alpha_vantage/TICKER_news.json 구조 (날짜가 key인 dict)
  - social_data/TICKER_social.json도 동일하게 날짜 key dict 구조

할 일: poison_local_data.py 신규 작성
  - 클래스: LocalDataPoisoner
  - 메서드:
      poison_news(ticker, date_range, attack_goal, n_articles=3)
        → news_data/alpha_vantage/{ticker}_news.json 에서
          해당 날짜 범위 각 날짜에 악성 article n_articles개 prepend
          백업: news_data/alpha_vantage/{ticker}_news.json.bak

      poison_social(ticker, date_range, attack_goal, n_posts=3)
        → social_data/{ticker}_social.json 에서
          해당 날짜 범위 각 날짜에 악성 post n_posts개 prepend
          백업: social_data/{ticker}_social.json.bak

      restore(ticker)
        → .bak 파일로 원본 복원

  - attack_goal 별 페이로드:
      force_buy  → 극도로 낙관적 기사/포스트 삽입
      force_sell → 극도로 비관적 기사/포스트 삽입
      force_hold → 불확실성 극대화 기사/포스트 삽입

  - poisoned_news / poisoned_social config flag 활용 (기존 local.py 호환)
  - news_data_poisoned/, social_data_poisoned/ 디렉토리에 저장
    (원본은 건드리지 않음 — config["poisoned_news"]=True 시 별도 디렉토리 읽도록
     local.py가 이미 구현되어 있음)
